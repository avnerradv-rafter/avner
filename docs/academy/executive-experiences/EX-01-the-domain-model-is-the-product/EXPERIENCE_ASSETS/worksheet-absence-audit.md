# Worksheet — The Absence Audit

**EX-01 · Segment 2 · 15 minutes · Pairs**

> Source: exercise **E1**, principle **LL-01 — absence is the loudest signal**.

---

The fastest way to understand a system is not to list what it does. It is to find what it **cannot say**.

Below are five facts that any system serving a litigation practice should be able to express. Working in pairs, attempt each one against the instance in front of you. Do not design a fix. Do not discuss whether it matters. Record only what happens when you try.

| # | Try to record this fact | Where did you look? | Could the system express it? |
| --- | --- | --- | --- |
| 1 | **A hearing** — this matter is before this court, on this date, before this judge | | ☐ Yes ☐ Partly ☐ **No** |
| 2 | **A court** — which forum this matter sits in, and its jurisdiction | | ☐ Yes ☐ Partly ☐ **No** |
| 3 | **An opposing party** — who is on the other side, and who represents them | | ☐ Yes ☐ Partly ☐ **No** |
| 4 | **A limitation date** — the date by which this claim must be brought, and the rule it derives from | | ☐ Yes ☐ Partly ☐ **No** |
| 5 | **A concluded matter** — this file is finished, and here is its outcome | | ☐ Yes ☐ Partly ☐ **No** |

---

**One line only — do not elaborate:**

What did the system turn out to be, judged by what it could not say?
