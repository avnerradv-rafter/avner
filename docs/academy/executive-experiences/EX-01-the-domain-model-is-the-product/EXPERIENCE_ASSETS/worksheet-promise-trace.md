## The rule that governs this worksheet

> **A promise marked unsatisfiable must name the missing structure.**
>
> *"Unsatisfiable because it's badly built"* — **fails.**
> *"Unsatisfiable because no hearing entity exists"* — **passes.**

This is quality gate **G2**, inherited from LREF-01 §S2. A verdict without a named structural cause is an opinion, not a finding.
