# Standing Libraries

**Permanent Academy assets.**

Case studies are output. The libraries are the asset — they outlive any single analysis and are what makes the *n*th study more valuable than the first.

| Library | Location | Fed by | Accumulation rule |
| --- | --- | --- | --- |
| **Pattern Library** | [`Pattern-Library.md`](./Pattern-Library.md) | S9, eight fixed categories | Observed in two independent subjects → *confirmed*. Contradicted → *contested*, annotated with the conditions under which each holds |
| **Lesson Library** | [`Lesson-Library.md`](./Lesson-Library.md) | S8 | Recurrence across independent subjects raises confidence — the strongest evidence a failure is structural rather than incidental |
| **Instrument Library** | [LREF-01 §8](../LREF-01/LREF-01-Methodology.md#8-the-instrument-library) | §8, plus §14 amendments | Retained while productive; retired after three barren studies |

**The Instrument Library is held in the methodology itself**, not duplicated here. The instruments are inseparable from the stages that apply them, and a second copy would drift.

## Using the libraries

**Starting a study.** The Pattern Library's entity model (§4) is the reference model S6 compares the subject against. The Lesson Library tells you which failures to look for first.

**Finishing a study.** Promote patterns into the eight categories and lessons by principle. Where a promoted item matches an existing entry, add the instance and raise its status rather than creating a duplicate. Where it contradicts one, mark the existing entry *contested* and record the conditions — never silently overwrite.

**Building.** The libraries are the design authority. A builder should be able to work from them without reading any case study; the case studies exist to evidence the libraries, not to be consulted in their place.

## Synthesis cadence

After every third case study, a synthesis pass reconciles the libraries: collides patterns, promotes and downgrades, retires unproductive instruments, and updates the reference model. Without it the libraries grow without converging.
